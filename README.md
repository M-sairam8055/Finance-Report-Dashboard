📊 Finance Report Dashboard
Hello Everyone,

This is a Finance Dashboard project created using Power BI. It visualizes key financial metrics from a structured dataset, making it easier for decision-makers to analyze business performance over time.

🧩 Problem Statement
The goal of this project is to build a clear and interactive dashboard that:

Highlights important financial KPIs like Units Sold, Gross Sales, and Profit

Provides visuals to understand performance by Quarter, Month, Country, and Segment

📌 Features of the Report
This dashboard includes:

🎯 Cards showing Total Units Sold, Total Gross Sales, and Total Profit

📅 Slicers to filter data by Year, Country, and Segment

📊 A Quarter-wise bar chart showing profit trends across years

🌐 A Monthly area chart showing profit patterns throughout the year

🔄 A Reset Button to quickly clear all slicer selections (hold Ctrl and click to reset)

🚀 How to Use
Open the Finance.pbix file using Power BI Desktop

Use slicers to explore data by year, segment, or country

Hover over visuals to see insights and detailed tooltips

To reset all filters, click the reset button while holding Ctrl

📁 Files Included
Finance.pbix – Main Power BI report

financial_data.csv – The dataset used to build the visuals
